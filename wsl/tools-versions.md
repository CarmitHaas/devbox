# Updating the tools later

`bootstrap.sh` skips anything already installed, so upgrades are manual. One line each.
Pinned installs: set the matching variable, remove the binary, re-run `bootstrap.sh`
(for example `sudo rm /usr/local/bin/helm && HELM_VERSION=v3.16.2 bash wsl/bootstrap.sh`).

| Tool | Installed via | Update with |
|---|---|---|
| apt basics (jq, tmux, ripgrep, fzf, bat, fd, ...) | apt | `sudo apt-get update && sudo apt-get upgrade` |
| gh | apt repo (cli.github.com) | `sudo apt-get update && sudo apt-get install --only-upgrade gh` |
| kubectl | apt repo (pkgs.k8s.io, one minor channel) | same minor: `sudo apt-get install --only-upgrade kubectl`; new minor: edit `/etc/apt/sources.list.d/kubernetes.list` to the new `v1.xx`, re-fetch the Release.key, `apt-get update`, `apt-get install kubectl` |
| terraform | apt repo (apt.releases.hashicorp.com) | `sudo apt-get install --only-upgrade terraform` (pin a version with `apt-mark hold terraform`) |
| helm | tarball from get.helm.sh | `sudo rm /usr/local/bin/helm && bash wsl/bootstrap.sh` (or `HELM_VERSION=v3.x.y` first) |
| yq | GitHub release binary | `sudo rm /usr/local/bin/yq && bash wsl/bootstrap.sh` |
| terragrunt | GitHub release binary | `sudo rm /usr/local/bin/terragrunt && bash wsl/bootstrap.sh` |
| k9s | GitHub release .deb | `sudo rm /usr/local/bin/k9s 2>/dev/null; sudo apt-get remove -y k9s; bash wsl/bootstrap.sh` |
| kubectx, kubens | GitHub release binaries | `sudo rm /usr/local/bin/kubectx /usr/local/bin/kubens && bash wsl/bootstrap.sh` |
| stern | GitHub release binary (`--extras`) | `sudo rm /usr/local/bin/stern && bash wsl/bootstrap.sh --extras` |
| aws CLI v2 | official zip installer | `sudo rm /usr/local/bin/aws && bash wsl/bootstrap.sh` (the installer runs with `--update`) |
| zoxide | official install script | `zoxide` has no self-update; `rm ~/.local/bin/zoxide && bash wsl/bootstrap.sh` |
| starship | official install script | `rm ~/.local/bin/starship && bash wsl/bootstrap.sh`, or `starship` prints a notice when a new version exists |
| uv | astral installer | `uv self update` |
| fnm | install script | `rm -rf ~/.local/share/fnm && bash wsl/bootstrap.sh` |
| Node | fnm | `fnm install 22 && fnm default 22` (new major: `fnm install 24 && fnm default 24`); remove old with `fnm uninstall <ver>` |
| npm | ships with Node | `npm install -g npm@latest` |
| Copilot CLI | npm | `npm install -g @github/copilot` (same command installs or updates); see `../copilot/` |
| direnv | apt (`--extras`) | `sudo apt-get install --only-upgrade direnv` |
| Python tools | uv | `uv tool upgrade --all` |
| faster-whisper (transcribe.sh) | uv venv in `~/.local/share/devbox/transcribe` | `uv pip install --python ~/.local/share/devbox/transcribe/bin/python -U faster-whisper`; models cache in `~/.cache/huggingface/` |
| pip (user) | apt python3-pip | `python3 -m pip install --user --upgrade pip` |
| bash completions cache | generated by `40-tools.sh` | automatic: regenerated when the binary is newer than the cache (`~/.cache/devbox/completions/`) |
| corporate CA | `install-corp-ca.sh` | when IT rotates the CA: re-run `windows/export-corp-ca.ps1`, then `bash wsl/install-corp-ca.sh` |
| dotfiles | `install-dotfiles.sh` | `git pull` in `~/src/devbox`, then `bash wsl/install-dotfiles.sh` (backups kept as `.bak.<timestamp>`) |
| WSL itself | Windows | `wsl --update` in PowerShell; `wsl --version` to check |
| Ubuntu release | apt | stay on 22.04 while the team does; `sudo do-release-upgrade` when they move |

Check everything at once: `bash wsl/bootstrap.sh` prints a versions table at the end
without changing anything that is already installed.
